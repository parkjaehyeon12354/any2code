보류 게시물

        
금칙어가 감지되어 자동으로 가려진 글입니다. 확인 후 공개하거나 제재하세요.

      


      

        ⓘ
        자동 필터는 오탐이 생깁니다.
        감지된 단어를 강조해 두었으니 문맥을 보고 판단하세요.
        차단해도 글은 지워지지 않으니 언제든 되돌릴 수 있습니다.
      


      


      

        

          
보류 중 

        

        

          

            
작성자내용감지어작성일상태

            
          

        

      

    


    
    

      

        
AI 크레딧

        
AI 과학 도우미 사용량입니다. 3시간마다 자동으로 채워집니다.

      


      

        ⓘ
        여기서 준 크레딧은 다음 초기화 때 사라집니다.
        한국 시간 00시 기준 3시간마다(00·03·06·09·12·15·18·21시) 모두
        2000 크레딧으로 돌아갑니다. 시연 중 소진처럼
        지금 당장 필요한 경우에만 쓰세요.

이름로그인남음사용마지막 사용

            
          

        

      

    


    
    

      

        
쿠폰

        
크레딧 충전 쿠폰과 요금제 쿠폰을 발급합니다. 사용자는 설정 화면에서 코드를 입력합니다.

      


      

        ⓘ
        충전 크레딧은 3시간 초기화로 사라지지 않고 다 쓸 때까지 남습니다.
        요금제 쿠폰은 3시간마다 채워지는 양을 늘리고 Gemini 를 열어 줍니다. 같은 요금제를 또 쓰면
        기간이 이어 붙고, 다른 요금제가 적용 중인 사람은 쓸 수 없습니다.

설정

        
자동 필터와 도배 기준을 조정합니다. 나머지는 Azure 포털에서만 바뀝니다.

      


      

        ⓘ
        저장하면 다음 글부터 적용됩니다. 이미 올라간 글을 다시
        판정하지는 않습니다 — 보류 이유는 걸릴 당시 기준으로 남아야 판단할 수 있기 때문입니다.
      


      


      

        

          
자동 필터

          
        

        

          

            
            
            글이나 답변에 이 중 하나라도 들어가면

            비워두면 필터가 꺼집니다.

서버 상태

        

          

          이 값들은 Azure 앱 설정(환경 변수)이라 이 화면에서는 바꿀 수 없습니다.
          관리자 세션이 탈취된 상황을 가정하면, 점검 스위치와 관리자 목록만은 사이트 로그인으로
          건드릴 수 없어야 합니다.

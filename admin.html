보류 게시물

        
금칙어가 감지되어 자동으로 가려진 글입니다. 확인 후 공개하거나 제재하세요.

      


      

        ⓘ
        자동 필터는 오탐이 생깁니다.
        감지된 단어를 강조해 두었으니 문맥을 보고 판단하세요.
        차단해도 글은 지워지지 않으니 언제든 되돌릴 수 있습니다.
      


      


      

        

          
보류 중 

        

        

          

            
작성자내용감지어작성일상태

            
          

        

      

    


    
    

      

        
설정

        
자동 필터와 도배 기준을 조정합니다. 나머지는 Azure 포털에서만 바뀝니다.

      


      

        ⓘ
        저장하면 다음 글부터 적용됩니다. 이미 올라간 글을 다시
        판정하지는 않습니다 — 보류 이유는 걸릴 당시 기준으로 남아야 판단할 수 있기 때문입니다.
      


      


      

        

          
자동 필터

          
        

        

          

            
            
            글이나 답변에 이 중 하나라도 들어가면
            자동으로 보류되고 보류 게시물 화면에 올라옵니다. 지워지는 게 아니니 오탐이면 공개하면 됩니다.
            비워두면 필터가 꺼집니다.
          

        

      


      

        
도배 기준

        

          

            한 사람이 글·답변을 올릴 수 있는 한도
            

              최근
              
              분에
              
              개까지
            

            넘으면 작성을 거절하고 "잠시 후에 다시 작성해 주세요" 가 뜹니다.
            글과 답변에 각각 적용됩니다.
          


          

            
            
            
          

        

      


      

        
서버 상태

        

          

          이 값들은 Azure 앱 설정(환경 변수)이라 이 화면에서는 바꿀 수 없습니다.
          관리자 세션이 탈취된 상황을 가정하면, 점검 스위치와 관리자 목록만은 사이트 로그인으로
          건드릴 수 없어야 합니다.
